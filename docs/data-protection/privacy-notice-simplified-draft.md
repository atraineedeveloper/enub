# Borrador — Aviso de Privacidad Simplificado del sistema ENU

> **NO VIGENTE / NO MOSTRAR COMO AVISO OFICIAL.** Borrador para validación institucional. Debe sustituirse todo campo pendiente antes de integrarlo en formularios o cargas de documentos.

**Responsable:** **PENDIENTE DE VALIDACIÓN INSTITUCIONAL** — confirmar la denominación jurídica exacta del Responsable y su domicilio.

El sistema ENU tratará los datos personales que resulten necesarios para administrar el expediente y perfil de las personas trabajadoras; gestionar información laboral, profesional y académica; administrar horarios, asignaturas y actividades; habilitar autenticación, vinculación de cuenta y control de acceso; integrar y mantener documentos requeridos para procesos institucionales; y atender correcciones de identidad/correo relacionadas con el acceso al sistema.

Algunos documentos académicos, docentes, de tutoría o asesoría pueden contener datos personales de estudiantes o terceros. **PENDIENTE DE VALIDACIÓN INSTITUCIONAL:** confirmar el alcance autorizado de esos documentos y las finalidades correspondientes.

**Transferencias:** **PENDIENTE DE VALIDACIÓN INSTITUCIONAL.** Deben indicarse únicamente las transferencias que jurídicamente correspondan, sus destinatarios y finalidades, identificando cuáles requieren consentimiento. Los proveedores tecnológicos no deben clasificarse automáticamente como transferencias sin revisar su figura jurídica y contractual.

**Negativa para finalidades o transferencias que requieran consentimiento:** **PENDIENTE DE VALIDACIÓN INSTITUCIONAL.** Incorporar el mecanismo aprobado o indicar, con fundamento validado, que no existen finalidades/transferencias de esa naturaleza.

El aviso de privacidad integral aprobado podrá consultarse en: **PENDIENTE DE VALIDACIÓN INSTITUCIONAL — ruta pública propuesta `/privacy` y/o portal institucional aplicable**.

**Versión/fecha de aprobación:** **PENDIENTE DE VALIDACIÓN INSTITUCIONAL**.
