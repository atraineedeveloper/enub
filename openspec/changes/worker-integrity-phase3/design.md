# Design

Production read-only inspection 2026-11-25: worker max 56 / sequence 1; plaza max 67 / sequence 66; admission max 103 / sequence 16. HTTP 409 on edit: primary key violations in both relation tables. Repair by transactional ALTER SEQUENCE RESTART under table locks, never move a sequence backward. Separately introduce SECURITY INVOKER creation RPC with staff/admin RLS insert policy; reuse existing update RPC inside the same transaction. Explicit worker column allowlist; validation before upload; reject duplicate keys per worker and duplicate admission types in submitted arrays. Existing SQL update accepts historical admission labels (Ingreso/Reingreso), so do not restrict those to current UI options. Do not introduce global uniqueness on RFC or payment keys without institutional confirmation. Uncertain transport failures must not delete a potentially committed photo. Storage reconciliation remains separate; no deletion of existing files.
