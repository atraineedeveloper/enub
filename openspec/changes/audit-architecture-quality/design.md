# Design

Use TypeScript's existing compiler API for a read-only source inventory: file/line counts, explicit any nodes, assertions, non-null expressions, suppression comments, relative import edges and strongly connected components. Exclude generated database types and font assets from hotspot rankings. Metrics are review signals, not proof of defects. Classify tests separately; do not print source contents or environment values. Subsequent refactors must have targeted regression tests and preserve public contracts.
