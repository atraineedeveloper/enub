# Design

Use pinned Supabase CLI v2, standard logical dump, age public recipient (private identity never in GitHub), encrypted artifact only. SQL dump steps are separate snapshots: use quiet window for pre-migration backup, compare data fingerprints, not guaranteed atomic with Storage. Storage inventory uses known two buckets, paginated listing and size checking, manifest retains original paths and hashes, 100 MB cap initially. 350 MB repository backup-artifact cap, fail closed, no deletion, GitHub account-wide usage still needs monitoring. 14/21 day retention. Keep account budget $0. No PR run has production secrets; synthetic encryption test only. Service key is privileged; use trusted main and restricted repo access. Full restoration of managed auth/storage settings and custom policies needs independent test; no claims of complete recovery until proven.
